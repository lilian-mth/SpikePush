# 🗡️ SpikePush

**▶️ [Jouer à SpikePush sur liliandev.com](https://liliandev.com)**

> **Poussez. Cachez-vous. Survivez.**

**SpikePush** est un *party game* multijoueur sur navigateur en vue *top-down*. 

Le but est simple : survivre à des piques mortelles qui sortent des murs en se cachant derrière les rares couvertures disponibles. Le problème ? Il n'y a pas assez de place pour tout le monde. Analysez les zones de danger, ruez-vous vers un abri, et n'hésitez pas à bousculer vos adversaires pour voler leur place !

## 🎮 Contrôles

Le jeu est jouable directement dans le navigateur, sur ordinateur comme sur mobile.

*   **PC :** Touches `Z`, `Q`, `S`, `D` pour se déplacer.
*   **Mobile :** Joystick tactile virtuel.

## 🛠️ Stack Technique

Le projet est construit autour d'une architecture web classique pour garantir un accès sans téléchargement :

*   **Frontend :** HTML5, CSS3, JavaScript (Vanilla).
*   **Backend :** Node.js (hébergé sur Render) pour la gestion du multijoueur.
*   **Base de données :** Hostinger (gestion des profils, amis et sauvegardes).
